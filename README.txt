## Onionskyn — Gap4456 Fork

Modified version of the original Onionskyn animation editor.

**Changes:**
- Added multiple UI themes.
- Improved Motion Tween rotation controls and interpolation.
- Added Copy, Cut and Paste Frames functionality.
- Improved timeline frame handling.
- Added ghost placeholders for empty symbol frames.
- Added Save / Don't Save / Cancel confirmation when closing the Electron desktop application.
- Various UI fixes.

**Warning:** These modifications are experimental and have not been thoroughly tested. Some changes may have broken existing features, including potentially essential functionality. Stability and compatibility are not guaranteed. Use at your own risk and keep backups of important projects.
