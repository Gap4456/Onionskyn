# Getting started

## The screen

- **Toolbar (left):** drawing and selection tools. Hover any tool to see its name and shortcut.
- **Stage (centre):** the canvas you draw on. Space-drag pans, Ctrl+wheel zooms, and the zoom percentage at the bottom clicks to fit the view.
- **Timeline (bottom):** one row per layer, one column per frame. Click the ruler to scrub; right-click any cell for frame and tween actions.
- **Properties panel (right):** tabs for the selected object, the document, the Library and more. Toggle it with the Properties button.
- **Menus (top):** **File** (new, open, import image, save, Library, report a problem) and **Export** (video, GIF, image, image sequence, HTML5 player).

## Starting out

The first time you open Onionskyn it loads a sample animation: press **Enter** to play it, then try the Selection tool on the ball. **File → New animation** gives you a blank document; **File → Load sample animation** brings the demo back.

## Saving

- **Ctrl+S** (or File → Save project) downloads a `.onionskyn.json` project file that includes your images and sounds. This is your real backup.
- Onionskyn also autosaves to the browser as you work and restores it next time. Browser storage can be cleared or limited (private windows especially), so save a file for anything you care about.
- If an image or sound is missing from the document when you save, you get a warning.
- File → Open accepts `.onionskyn.json`, older FlashCraft projects, and Adobe `.fla` files.
