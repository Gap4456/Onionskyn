# Keyboard shortcuts

Press **?** in the app to see this list any time. On a Mac, use Cmd in place of Ctrl.

| Keys | Action |
| --- | --- |
| V / A | Selection / Node edit |
| P / Y / B / F | Pen / Pencil / Brush / Fluid brush |
| [ and ] | Brush size smaller / larger |
| L, R, O | Line, Rectangle, Ellipse |
| T | Text |
| K / I / H | Paint bucket / Eyedropper / Hand |
| F8 | Convert selection to symbol (Fn+F8 on some laptops) |
| F9 | Script editor |
| F5 / F6 / F7 | Insert frame / keyframe / blank keyframe |
| Shift+F5 / Shift+F6 | Remove frame / clear keyframe |
| , and . | Previous / next frame |
| Enter | Play or stop (finishes a pen path) |
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Ctrl+C, X, V, D | Copy, cut, paste, duplicate |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo |
| Ctrl+S | Save project |
| Arrow keys | Nudge (Shift = 10 px) |
| Space-drag | Pan the stage |
| Ctrl+wheel | Zoom |
| Shift / Alt while drawing | Constrain / draw from centre |
